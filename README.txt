APK OLUŞTURMA (Android Studio)
1. Android Studio'yu açın: File > Open > bu klasörü (OgrenciIsleri) seçin.
2. Gradle eşitlemesi bitsin (internet gerekir, ilk seferde birkaç dakika).
3. Build > Build Bundle(s) / APK(s) > Build APK(s)
4. "locate" bağlantısı: app/build/outputs/apk/debug/app-debug.apk
5. APK'yı telefona atın, "bilinmeyen kaynaklardan yükleme" iznini verip kurun.
Not: HTML dosyası app/src/main/assets/index.html içindedir; güncellemek için bu dosyayı değiştirip yeniden derleyin.
